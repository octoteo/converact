# Changelog

## 1.0.0 - 2026-09-09

First stable Converact release.

### Added

- Contract Core with semantic validation and normalized digest compilation.
- L0-L3 deterministic risk classification.
- Repository inspection and bounded context compilation.
- Command, file, and explicit/manual evidence checks.
- Evidence freshness binding to both contract digest and implementation workspace fingerprint.
- MUST/SHOULD convergence engine and convergence-gated acceptance.
- Universal Node.js CLI with structured JSON output.
- MCP stdio server using the stable `@modelcontextprotocol/server` v2 API.
- Universal Converact Agent Skill.
- Composite GitHub Action and Node 20/22 CI.
- JSON Schema, security documentation, architecture documentation, and automated tests.
